# panorama

> Part of the [VC Map Project](https://github.com/virtualcitySYSTEMS/map-ui)

Advanced settings plugin for viewing panorama images in the VC Map.

## Features

This plugin provides comprehensive controls for panorama image viewing:

### Image Enhancement

- **HDR Support**: Toggle High Dynamic Range rendering
- **Brightness & Contrast**: Adjust image brightness (-100% to +100%) and contrast (0% to 400%)
- **Gamma Correction**: Fine-tune gamma values (0.1 to 5.0)
- **Exposure Control**: Adjust exposure levels (0 to 5.0)

### Complementary Images

- **Depth Overlay**: Display depth information from panorama images
- **Intensity Overlay**: Show intensity data overlay
- **Opacity Control**: Adjust transparency of overlays (0% to 100%)

### Visibility Controls

- **Layer Toggle**: Show/hide additional map layers in panorama view
- **Cursor Visibility**: Toggle the panorama cursor on/off
- **Footprint Display**: Show/hide panorama location markers on the map

### Image Metadata

View detailed information about the current panorama image:

- Image name and timestamp
- Geographic position (WGS84 coordinates)
- Camera offset
- Tile size
- Available data types (depth/intensity)
